# Ledger Camurim — mantido pelo Claude

Este é o novo modelo de controle financeiro da Camurim Incorporações, substituindo a leitura ao vivo do Google Sheets (que se mostrou pouco confiável). A partir de agora, os arquivos desta pasta são a fonte de verdade, e o Claude os mantém conforme você reporta novas despesas/eventos no chat.

## Como funciona

1. Você me conta (por texto ou áudio) sobre um novo lançamento — despesa, aporte, venda, transferência para a JV, etc.
2. Eu registro no arquivo certo desta pasta.
3. Periodicamente eu regenero o painel de gestão com os dados atualizados.

Os arquivos originais no Google Sheets (Capital Social, ARCA.CAMURIM, Duas Primeiras Casas, Atas) continuam existindo, mas passam a ser só o histórico congelado até 12/07/2026 — o painel não lê mais nada ao vivo do Drive. **Migração completa: o painel agora é 100% local, sem nenhuma dependência do Google Drive.**

Adicionado o comparativo com faseamento (só inicia o lote seguinte quando o anterior chega ao "mês de entrega prática"). Resultado: no cenário Camurim sozinha, faseando, o caixa **deixa de ficar negativo** (de -R$352.798,54 pra nunca cair abaixo dos R$32.878,57 iniciais) — o intervalo entre construir e vender é suficiente pra proteger o caixa sem JV nem aporte extra, mas o projeto todo passa de 10 para 22 meses. No cenário JV, simultâneo ou faseado dá na mesma (caixa nunca fica negativo em nenhum dos dois).
  - **Simulador interativo**: 3 sliders (um por lote) pra testar qualquer cronograma, não só "tudo junto" ou "um de cada vez". Atualiza ao vivo o gráfico de caixa, o pior momento de caixa e o saldo final de cada modelo (JV/Sozinha). Testado com alguns cronogramas intermediários — por exemplo, atrasar só 3 meses entre lotes (metade do faseamento "automático") já é suficiente pra manter o caixa positivo na maioria dos casos, então dá pra comprimir o prazo de ~22 meses sem reabrir o problema de caixa.
